プライバシーポリシー

制定日：2026年10月17日／改定日：2026年10月22日

Tabi Note（以下「本アプリ」）の運営者（以下「運営者」）は、本アプリの利用者（以下「利用者」）の情報を次のとおり取り扱います。

1. 運営者が取得する情報

本アプリにはアカウント登録がなく、運営者が利用者の氏名・メールアドレス・電話番号などを取得することはありません。

利用者が地図に塗った記録（地域とレベル、行った記録（行った日・メモ・写真・URL・費用）、コレクションの記録）は、利用者の端末と、利用者ご本人の iCloud（Apple の CloudKit のプライベート領域）にだけ保存されます。運営者はこの記録を見ることも、取り出すこともできません。

行った記録の写真：利用者が選んだ写真だけを、縮小して（撮影場所などの写真の情報は付けずに）記録と一緒に保存します。保存先は上と同じく、利用者の端末と利用者ご本人の iCloud だけです。

写真から塗る：利用者が許可した場合に限り、写真の撮影場所と撮影日を端末の中だけで読み取り、行った都道府県・国を見つけます。この機能で読み取った写真・位置情報・撮影日が端末の外に送られることはなく、運営者が取得することもありません。

近くのスポット（位置情報）：利用者が許可した場合に限り、「近く」の画面を開いたときだけ現在地を1回取得し、今いる都道府県・市区町村・国と、近くのスポットを探すためだけに端末の中で使います。本アプリは位置情報を保存せず、外部（運営者を含む）に送ることもありません。

思い出の通知：利用者がオンにした場合に限り、前の年の同じ日に行った場所を知らせる通知を、端末の中だけで作って予約します（通知の文面と添える写真は、端末の中の記録から作ります）。この機能のために記録が外部に送られることはなく、運営者が取得することもありません。

次のパックへの投票：利用者が投票した場合、投票した候補と、Apple が本アプリ用に発行する匿名の利用者ID（氏名や Apple アカウントのメールアドレスとは結び付きません）を、iCloud の公開領域（CloudKit の公開データベース）に保存します。1人1票にするためと、投票数を表示するためだけに使います。投票はいつでも取り消せます。

パックの配信：コレクションのパックのデータを、本アプリのウェブサイト（GitHub Pages でホストしています）から取得します。その際、通信に必要な IP アドレスなどがホスティング事業者（GitHub, Inc.）に送られます。

2. 外部サービスが取得する情報

本アプリは次の外部サービスを利用しています。各サービスはそれぞれのプライバシーポリシーに従って情報を取り扱います。

サービス目的取得される主な情報
Google AdMob
（Google LLC）		無料版での広告の表示・効果測定広告識別子などの端末ID、IPアドレスから推定されるおおよその位置、表示・操作した広告、アプリの操作、パフォーマンス・クラッシュなどの診断情報
RevenueCat
（RevenueCat, Inc.）		Tabi Note Pro・パックの購入状態の確認購入履歴、匿名の利用者ID（氏名やメールアドレスとは結び付きません）
Apple
（Apple Inc.）		App Store での購入、iCloud での同期・投票の保存Apple のプライバシーポリシーに基づく情報
GitHub
（GitHub, Inc.）		ウェブサイトとパックのデータの配信IP アドレスなどの通信の記録

Google の広告に関するポリシー／ RevenueCat のプライバシーポリシー／ Apple のプライバシーポリシー／ GitHub のプライバシーステートメント

3. 広告とトラッキング

無料版では Google AdMob による広告を表示します。初回起動時に、iOS の「App Tracking Transparency」による確認画面を表示し、利用者が許可した場合に限り、広告識別子を他社のアプリやウェブサイトをまたいだ広告の最適化に利用します。許可しない場合も、広告は利用者に合わせない形で表示されます。

許可はいつでも iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」から変更できます。欧州経済領域・英国・スイスなどの利用者は、本アプリの「設定」→「広告のプライバシー設定」から同意の内容を変更できます。

Tabi Note Pro を購入すると広告は表示されなくなり、広告のための SDK も起動しません。

4. 外国にある第三者への提供

前項の外部サービスにより、情報がアメリカ合衆国などの外国で取り扱われることがあります。これらの事業者は、各国の個人情報保護制度のもとで、それぞれのプライバシーポリシーに従って情報を取り扱います。

5. 記録の削除

本アプリの「設定」→「すべての記録を消す」で、端末と iCloud の記録を削除できます。iPhone の「設定」→ 利用者名 →「iCloud」からも、本アプリの iCloud データを削除できます。投票は、コレクション画面の投票ボタンをもう一度押すと取り消せます。

6. このポリシーの変更

内容を変更する場合は、このページで改定日とともにお知らせします。
